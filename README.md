# WaveT
Evolution of electron/vibronic wavefunctions under external electromagnetic perturbations. Computing and analyzing electron dynamics, simulating spectra (absorption, circular dichroism, Ramn, 2DES, X-ray spectroscopies). Theory of open quantum systems via the stochastic Schrödinger equation.

# TDPLas
Boundary element method in frequency and time domain for general-shape nanoparticles. Quantized plasmons. Dummy surface. Interface with Octopus. Coupled to WaveT.
